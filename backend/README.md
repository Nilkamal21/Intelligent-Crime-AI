# KSP Crime AI Backend Subsystem

This subdirectory houses the FastAPI application server, database models, CSV loaders, financial transactional seeder pipelines, statistical forecasting modules, and ReportLab PDF exporters.

---

## Directory Structure & Contents

### 1. [app/](file:///C:/Users/adhik/OneDrive/Desktop/ksp-crime-ai/backend/app) (Backend Core Module)
Contains main API routers, ORM schemas, global database connectors, path configurations, and custom data processing frameworks.

### 2. [exports/](file:///C:/Users/adhik/OneDrive/Desktop/ksp-crime-ai/backend/exports) (PDF Export Cache)
The destination directory where dynamically compiled KSP intelligence briefing PDF reports are stored.

### 3. [.env](file:///C:/Users/adhik/OneDrive/Desktop/ksp-crime-ai/backend/.env) (Local Configuration Variables)
Specifies localized environment bindings including paths, Groq API keys, and authorization settings.

### 4. [requirements.txt](file:///C:/Users/adhik/OneDrive/Desktop/ksp-crime-ai/backend/requirements.txt) (Python Dependencies)
Defines all python packages required to run the server:
* `fastapi` & `uvicorn` (Core ASGI routing & development server)
* `pandas` & `numpy` (High-speed matrix analytics & query manipulation)
* `sqlalchemy` (SQL database mappings & connection poolers)
* `reportlab` (Briefing PDF compiler)
* `groq` (LLM query client)
* `scikit-learn` (Local TF-IDF RAG & linear regressions)
* `statsmodels` (ARIMA & Exponential Smoothing)
* `python-jose` & `passlib` (JWT generation & secure authentications)

### 5. [seed.db](file:///C:/Users/adhik/OneDrive/Desktop/ksp-crime-ai/backend/seed.db) (SQLite Database File)
The autogenerated local database storing RBAC users, transaction ledgers, audit trails, and chatbot histories.

## Initialization & Execution

To run the backend server:

1. Ensure Python 3.9+ is installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your Groq API Key inside `.env` or system environment variables:
   ```env
   GROQ_API_KEY=gsk_your_key_here
   ```
4. Start the Uvicorn server:
   ```bash
   python app/main.py
   ```
   Or run directly via Uvicorn:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```
5. Interactive API docs will be available at `http://127.0.0.1:8000/docs`.
